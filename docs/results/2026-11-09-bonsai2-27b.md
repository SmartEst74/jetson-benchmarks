## Command

With the compatible build's `llama-bench` on PATH, set `MODEL` to the exact GGUF. The fit target asks the runtime to leave 512 MiB of device margin during its fit calculation. The fit setting may choose different offload on another host.

```bash
MODEL=/path/to/Ternary-Bonsai-2-27B-PTQ1_0.gguf
args=(-m "$MODEL" -b 128 -ub 128 -t 6 -ctk f16 -ctv f16 -fa auto
      -fitt 512 -fitc 512 -r 3 -o json --progress)
timeout -k 5s 135s llama-bench "${args[@]}" -p 512 -n 128
timeout -k 5s 150s llama-bench "${args[@]}" -p 0 -n 32 -v
```

Use `-p 512 -n 0` to repeat just the prefill case. See the [memory preflight](../memory.md) before loading. Synthetic prefill and decode rates describe separate tests. Chat quality, time to first visible answer, vision, and extended-context stability remain unmeasured here.
